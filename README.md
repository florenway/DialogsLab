## Как запустить

1. Откройте папку проекта в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Запустите конфигурацию `app` на эмуляторе или телефоне.

Сборка из командной строки:

```bash
./gradlew assembleDebug
```

Нужны JDK 17 и Android SDK с `compileSdk` 35. Android Studio поставит их сама.

## Что делают кнопки

|Кнопка|Поведение|
|-|-|
|Кнопка 1|Toast «кнопка номер 1 нажата» на 2 секунды (`Toast.LENGTH\_SHORT`)|
|Кнопка 2|Toast «кнопка номер 2 нажата» на 3,5 секунды (`Toast.LENGTH\_LONG`)|
|Кнопка 3|Диалог с заголовком «кнопка 3» и иконкой `test\_icon`. «да» красит текст всех кнопок в красный. «отмена» закрывает окно и показывает Toast «Диалоговое окно закрыто»|
|Кнопка 4|Диалог с множественным выбором. Верный набор показывает Toast «Всё верно», любой другой прячет все кнопки|

Иконка `test\_icon` стоит в заголовке третьего диалога. После верного теста она же появляется на экране рядом с Toast «Всё верно».

Неверный ответ делает все четыре кнопки невидимыми. ФИО и группа остаются. Чтобы вернуть кнопки, запустите приложение заново.

Поворот экрана не сбрасывает красный текст, скрытые кнопки и отметку верного ответа.

## Тест «Ночь в музее»

Нужно отметить только музыкальные инструменты — все верные пункты и ни одного лишнего.

Верные пункты:

* Скрипка
* Рояль
* Флейта
* Виолончель

Лишние: мольберт, палитра, кисть.
